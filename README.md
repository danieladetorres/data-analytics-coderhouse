# RetailPro | Proyecto de Data Analytics

## Descripción del proyecto

RetailPro es un proyecto de análisis de datos orientado al estudio del desempeño comercial a partir de información de ventas, clientes, productos y categorías.

El objetivo del proyecto es analizar los factores que explican las variaciones en las ventas, identificar productos y clientes relevantes y transformar los datos disponibles en información útil para apoyar la toma de decisiones comerciales.

## Herramientas utilizadas

- SQL Server: creación y gestión de la base de datos.
- SQL: consultas, agregaciones, JOINs y análisis de información comercial.
- Power Query: limpieza, transformación y preparación de datos mediante procesos ETL.
- Power BI: modelado de datos, creación de medidas DAX y visualización.
- GitHub: almacenamiento, organización y documentación del proyecto.

## Estructura del repositorio

El repositorio contiene los principales entregables desarrollados durante el proyecto:

- `Ventas_tech_db.sql`: creación y estructura de la base de datos.
- `M4_CONSULTAS_NEGOCIO.sql`: consultas SQL orientadas al análisis de negocio.
- `M5_CONSULTAS_JOINS.sql`: consultas con JOINs para integrar información de distintas tablas.
- `m6_pipeline/`: documentación y archivos correspondientes al proceso ETL.
- `Módulo_8/`: modelo desarrollado en Power BI con relaciones, tabla calendario y medidas DAX.

## Cómo ejecutar los scripts SQL

1. Abrir SQL Server Management Studio.
2. Conectarse a una instancia de SQL Server.
3. Ejecutar primero `Ventas_tech_db.sql` para crear y preparar la base de datos del proyecto.
4. Verificar que la base de datos correspondiente se encuentre creada y seleccionada.
5. Abrir los scripts de consultas SQL.
6. Ejecutar las consultas del Módulo 4 y posteriormente las consultas con JOINs del Módulo 5.
7. Verificar los resultados obtenidos antes de utilizarlos para realizar conclusiones de negocio.

## Objetivo analítico

El análisis busca comprender el comportamiento de las ventas y evaluar el desempeño comercial considerando productos, categorías y clientes. Los resultados obtenidos sirven como base para la construcción de indicadores y visualizaciones que faciliten la toma de decisiones.
